# Sistema-De-Gastos

Este va a ser mi primer proyecto individual. voy a realizar un sistema de gastos digital que pueda tener seguimiento a todas las acciones que tome.
A futuro quiero que este sistema este en mi celular y en el de mi familia para que podamos hacer un seguimiento de nuestras finanzas

## Objetivo
Construir un sistema que permita:
- registrar ingresos y gastos
- categorizar movimientos
- consultar el balance total
- listar movimientos realizados
- filtrar información relevante

## Tecnologías
- Python
- SQLite
